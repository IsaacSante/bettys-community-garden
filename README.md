# Betty's Community Garden on Hull Street, Archive & Interactive Map

This repository houses the prototype and frontend skeleton for an independent urban garden documentation project. Developed as part of a collaborative summer residency, the site balances modern web interactions with accessible, multi-page layout design tailored for the community, neighbors, and local youth. Betty's Garden on Hull Street in Ocean Hill, Brooklyn, was built on and maintained in the Lenapehoking by 3-4 (?) Black women.

## Project Intentions

* **Historical Preservation:** Dedicated to archiving the foundational history of the garden. We arespecifically honoring the Black women community leaders who organized and established the space through land trusts and grassroots advocacy.

* **Oral History Mapping:** An interactive, lightweight spatial archive that links specific plots, old trees, and common spaces directly to audio and video recordings of gardeners' oral histories.

* **Botanical Care:** Provides a practical framework for community knowledge-sharing, including seasonal pruning guidelines, plant identification, and historical anecdotes.

* **Future Infrastructure:** Built to eventually host physical QR connections linking trees and bushes to their digital archival records. This framework is directly inspired by Ursula Endlicher’s *Plant Tags and Input Field Reversal* project via Harvestworks, exploring "HTML gardeness" by turning organic garden elements into physical interfaces for web-based data and performance archives.

## Technical Structure

This prototype is built entirely with clean, standard web technologies to ensure compatibility, high performance, and an easy transition to production hosting environments:

* **HTML5 & Vanilla CSS:** Styled with a minimal, structural layout inspired by high-contrast typographic design.

* **Leaflet.js:** Utilizes a non-geographical coordinate system (`L.CRS.Simple`) to turn a custom, handmade isometric watercolor illustration of the garden into a fully interactive, responsive map interface. Subject to change, based on the mapping needs and surveying insights.

* **Accessible Media Integration:** Built with responsive, native HTML5 audiovisual structures to seamlessly deliver oral history records on both desktop and mobile devices, as well as important dynamic calendars, plot maps, and bylaws accessible only to gardeners.
